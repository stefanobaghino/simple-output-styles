# Changelog

All notable changes to the plugin are documented here. Versions follow
[semantic versioning](https://semver.org): MAJOR for a renamed or removed
style, MINOR for a new or materially reworded style (with re-run evals),
PATCH for fixes that do not change how a style writes.

## 1.0.0 — 2026-08-10

First stable release.

- Six output styles: actionable-clarity, classic-concise, clarity-flow,
  developer-docs, plain-language, and technical-simplified.
- Each style measured with the evaluation harness; the README reports
  what each style does well and where it falls short.
- The `pick` skill recommends a style and sets it in your settings.
- The `feedback` skill gathers details and prefills the feedback forms.
